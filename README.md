# 李佳晖空间设计作品集

本目录为可直接发布到 GitHub Pages 的完整静态网站。

首页：index.html。图片、样式、脚本、视频及 PDF 均采用相对路径，无需外部字体或脚本服务。

将本目录内容上传到本人 GitHub 的公开仓库，保留 assets 文件夹结构。
在 Settings → Pages 中选择 Deploy from a branch，再选择 main 分支和根目录 / (root)。
网站地址以 GitHub Pages 发布成功后显示的链接为准。

不需要购买域名，不需要开启付费套餐。作品图片和求职联系方式随网站公开。
发布后仍需在国内手机关闭代理的情况下，用微信及浏览器检查实际访问效果。
